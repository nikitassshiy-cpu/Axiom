# Axiom (Fabric, Minecraft 26.2)

Клиентский мод: подсветка выбранных блоков и трейсеры, меню настроек.

## Как получить .jar без установки чего-либо
1. Создайте репозиторий на github.com и загрузите в него все файлы этой папки
   (кнопка Add file → Upload files; папку `.github` тоже обязательно).
2. Откройте вкладку **Actions** → workflow **Build Axiom** (запустится сам; либо Run workflow).
3. Когда сборка станет зелёной, откройте её и скачайте артефакт **Axiom-jar** (внутри `axiom-1.0.0.jar`).
4. Положите jar в папку `mods` вместе с **Fabric API 0.152.1+26.2** и Fabric Loader 0.19.3+.

## Локальная сборка
Нужны Java 25 и Gradle 9.5.1: `gradle build`, результат в `build/libs/axiom-1.0.0.jar`.

## Использование
Клавиша меню по умолчанию Right Shift (меняется в Настройки → Управление → Axiom).
Конфиг: `config/axiom.json`.
